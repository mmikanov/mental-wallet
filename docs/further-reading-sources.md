# Further Reading Sources — Curated Library Tools

Working document for reviewing sources before updating `curatedLibrary.ts`.

**Criteria applied:**
1. Talks specifically about the tool (not a generic list)
2. Explains why it works (mechanism), not just how to use it
3. URL verified as working
4. Better sources replace existing ones where applicable

**Legend:**
- ✅ KEEP = Existing link is good, retain it
- 🔄 REPLACE = Better source found for this slot
- ➕ NEW = Additional source to bring total to 3

**Explanatory Title** = The display title users will see in the app. Where the article uses different terminology than our tool, a parenthetical bridges the gap. Where the title already matches, it stays as-is.

## Notes for Review

- All URLs have been verified as accessible (fetched successfully during research)
- Priority was given to: PubMed/PMC (NIH), Frontiers, university centers (Stanford, UC Berkeley), StatPearls, and reputable consumer sites (Psychology Today, Medical News Today, Verywell Mind)
- Each source explains the *mechanism* (why it works), not just the procedure
- Sources are tool-specific wherever possible rather than general technique lists
- The PDF links from self-compassion.org are Kristin Neff's published papers hosted on her institutional site
- **Explanatory Titles**: Where marked *(same)*, the original title already connects clearly to the tool name. Where a new title is provided, it bridges the terminology gap so users understand why the link is relevant.

This needs a replacement — same URL appears in tool 9 as a known bad link. Consider using the Bolier et al. PubMed link (23390882) here too, or finding a Three Good Things-specific meta-analysis.
