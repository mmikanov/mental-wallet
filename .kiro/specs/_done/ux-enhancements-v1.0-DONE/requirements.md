# UX Enhancements v1.0 — Requirements

## Introduction

A collection of UX improvements identified during user testing before initial release. These require behavior changes, new controls, or navigation modifications — beyond simple text/font tweaks.

## Items

### 1. Keyboard Covers Bottom Input Fields (Expanded Cards)

**Problem**: When a card is expanded and the user taps a text field near the bottom, the keyboard covers the input — making it impossible to see what's being typed.

**Expected**: The card content should scroll up or the input should remain visible above the keyboard when focused.

### 2. Move Crisis Resources Higher in Settings (or Main Menu)

**Problem**: Crisis resources are at the bottom of the Settings page under "Safety." A user in distress might not scroll that far.

**Expected**: Crisis resources should be more prominent — either at the top of Settings, or accessible from the main wallet menu (kebab menu or dedicated icon).

### 3. Add Crisis Link to All "Learn More" Rationale Sheets

**Problem**: Only cards tagged with distress-related emotions show the "In crisis? Get support" link in their rationale sheet. Users who are struggling may be using any tool — not just ones tagged for distress.

**Expected**: The "In crisis? Get support →" link should appear on ALL rationale sheets (every card's "Learn more"), regardless of category or emotion tags.

### 4. Mindful Walking — Option to Add Walk Length

**Problem**: The tool doesn't capture how long the walk was. Insights could show correlation between walk duration and mood.

**Expected**: Add an optional duration field (e.g., choice buttons: "5 min", "10 min", "15+ min") to the Mindful Walking card. The existing "Completed mindful walk" checkbox becomes redundant when duration is selected and should be removed.

### 5. Discreet Reminders (Notification Content)

**Problem**: Reminders show the tool's title in the notification (e.g., "Time for: 5-4-3-2-1 Grounding"). Depending on the tool, this may not be discreet enough if someone else sees the notification.

**Expected**: Option to use a generic/discreet notification message (e.g., "Your reminder" or "Time for your practice") instead of the tool name. Could be a per-card toggle or a global setting.

### 6. Privacy Details Accessible from Settings

**Problem**: The detailed Privacy Details screen (event types, what's collected, how to opt out) is only accessible during onboarding.

**Expected**: Add a "Learn more" link in the "Help improve the app" toggle description in Settings that navigates to the Privacy Details screen.
